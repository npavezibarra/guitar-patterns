# GuitarPatterns

GuitarPatterns is an interactive audio application for recording and analyzing guitar performance. 

## Fase 2A: Audio Input

### Cómo seleccionar una interfaz de audio (Focusrite, etc.)
1. Conecta tu interfaz de audio a tu Mac (por ejemplo, Focusrite USB Audio).
2. Abre la aplicación GuitarPatterns.
3. En la parte superior de la interfaz, busca el menú desplegable **"Audio Input"**.
4. Selecciona tu interfaz en la lista.
   - Si el navegador o sistema te solicita permisos de micrófono, acéptalos. 
   - Una vez concedido el permiso, los nombres reales de los dispositivos aparecerán en la lista (si antes decían "Unknown device").
5. Una vez conectado, el estado cambiará a **"Connected"** en color verde.
6. Toca la guitarra; el medidor de nivel (visualizado como bloques, ej. `[████░░░░░░░░░░░░░░░░]`) reaccionará inmediatamente a la señal RMS entrante.
7. Para evitar acoples de audio, la señal de la guitarra no se reproduce por los altavoces de la computadora (monitoreo directo a través de la Focusrite).

### Simulación
- Puedes presionar la barra espaciadora (`Space`) mientras grabas para simular notas visualmente, independientemente de la señal de entrada real de audio.
